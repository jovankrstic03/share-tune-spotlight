# Tune Share

Can you make me a functional react web application, it has to be simple but functional minimum viable product

It has to be connected to Supabase backend service and connected database

The application theme will be an application where people share and listen to music

The application has to have:

Registration of users

Logging of users

Page where all users can be seen

Function where you can see what music user listen to when you click on it

It should contain three pages:

The main page

Page for logging in into user account

Page where favourite music is

The application needs to have navigation between the pages

Application needs to have at least one form for entering data (login for example)

Data that has been entered has to be kept in supabase database

Application should show data from the database in special page

It needs to have functionality for detail, for example when you click on a user it shows which

music he listens to

Application needs to have basic authentication of users:

registration

logging in

logging out
